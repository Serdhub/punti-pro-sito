Sito statico in italiano (solo HTML/CSS/JS), indipendente dall'app mobile.
Nessun database, login, cookie, analytics, modulo o integrazione a pagamento.

## Pubblicazione

Carica il **contenuto** della cartella nella radice del tuo hosting: le pagine saranno
raggiungibili come `/privacy/`, `/elimina-account/` e `/supporto/`.
Tutti i collegamenti sono relativi, quindi il sito funziona anche in una sottocartella.
